02 / ტექსტი და სემანტიკა

კოდი, რომელსაც აზრი აქვს

HTML განსაზღვრავს შიგთავსის მნიშვნელობას. გააზრებული სტრუქტურა გეხმარება გვერდის წაკითხვასა და განვითარებაში. HTML და CSS განსხვავებულ ამოცანებს ასრულებს.

კარგი პროექტი პატარა, გასაგები ელემენტებისგან იწყება.
(სახელოსნოს სასწავლო პრინციპი)

მენტორის რჩევა: “ჯერ შიგთავსი დაალაგე, შემდეგ გააფორმე.” ინდექსის მაგალითია H₂O, ხარისხის მაგალითი კი 10².

სამუშაოს თანამიმდევრობა

  1. შექმენი დოკუმენტის სტრუქტურა.
  2. დაამატე შინაარსიანი სემანტიკური ელემენტები.
  3. დააკავშირე CSS და შეამოწმე განლაგება.
